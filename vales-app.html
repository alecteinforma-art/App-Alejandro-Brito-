⚠️ Cómo usar la cámara en el celular

El archivo no funciona desde Descargas. Para que la cámara y galería funcionen en Android e iPhone necesitas abrirlo desde un servidor web. Es gratis y toma 3 minutos:

1
Entra a github.com y crea una cuenta gratuita (o inicia sesión).
2
Crea un repositorio nuevo → ponle cualquier nombre → marca "Public".
3
Sube este archivo vales-app.html y renómbralo a index.html.
4
Ve a Settings → Pages → Branch: main → Save. GitHub te da una URL como:
https://tuusuario.github.io/tunombre/
5
Abre esa URL en Chrome o Safari de tu celular. ¡Listo! La cámara funcionará.

💡 También puedes usar netlify.com → arrastra el archivo → obtienes URL instantánea.
